### Idea: Hook and skill hardening residue — fail-open branches and unprobed arms

_Focus: nine defects in the harness layer as it stands — fail-open branches, unprobed guard arms, and documentation gaps — all left at review-round caps on hook and skill PRs._

## Why one doc

doc-7's own domain table names this cluster (*skills / rules / hooks*, 8 rows at measurement). Every member is a fail-open branch, an unprobed guard arm, or a documentation gap in `.claude/hooks/` or `.claude/skills/`, and every one arrived the same way: a review tail on a hook/skill PR that hit the round cap and got filed rather than iterated.

Checked and rejected as owners: **doc-64** / **doc-69** are the meta-harness *extraction* theme — a different axis. These are defects in the hooks as they stand, not portability work.

**Selection cost: low.** None has an independent trigger, and all touch the same two directories, so one PR closes them. Note the half-(2) relationship: this shape is the *stock* of the process-residue class; the inflow default is what stops it refilling.

## Members

- **TASK-306 — Three acknowledged fail-open gaps in cwd-drift + promise-ledger hooks** (filed 2026-07, was state:observable size:M). Three in-spec fail-open trade-offs from #1732: (a) the quote-strip that prevents false-blocking commit messages also blinds the guard to a genuinely-quoted drifted pathspec; (b) the `git -C` short-circuit substring-matches anywhere, so `git -C /other status && git add packages/x` waves a whole compound command through; (c) `promise-ledger-check.sh` re-reads and re-parses the full transcript JSONL every Stop event. Fix shapes: scan the git subcommand's arg tokens instead of quote-stripping wholesale; evaluate `-C` per pipeline segment; walk backward for the last user-turn boundary instead of a full forward pass. Trigger/cost: all fail-OPEN (miss a block), never false-block, so cost is a missed drift catch plus O(transcript) turn-end latency that grows with compacted sessions. Evidence 2026-09-04: `grep -n "strip_quoted\|git -C" .claude/hooks/cwd-drift-guard.sh` → both mechanisms present unchanged; `grep -n "json.loads" .claude/hooks/promise-ledger-check.sh` → still parses the transcript per-line, per invocation.
- **TASK-494 — Stop hooks do not filter `isSidechain` entries from transcript scans** (filed 2026-08, was state:ready size:S). Neither `promise-ledger-check.sh` nor `blocking-question-channel-check.sh` skips sidechain/subagent records, so a spawned agent can in principle pollute the turn-boundary, formal-channel, or final-text reads. Fix shape: skip records where `isSidechain` is truthy in both hooks' python blocks — verifying the actual field name against a live transcript first, since the producer is authoritative — plus a probe case per hook. Three riders fold in: header notes documenting that both are wired to Stop only (SubagentStop is a separate event); adding the `?!`-ending line to the documented false-negative list; and evaluating whether `final_text` extraction should be scoped to the turn slice. Trigger/cost: fail-open direction bounds damage to a spurious block-once or a missed reminder. Evidence 2026-09-04: `git grep -n "isSidechain\|sidechain" .claude/hooks/promise-ledger-check.sh .claude/hooks/blocking-question-channel-check.sh` → no match.
- **TASK-578 — Probe the fail-open and STATE_DIR-hardening branches across transcript-reading hooks** (filed 2026-08, was state:ready size:S). `context-size-reminder.probe.sh` and `queued-message-receipt.probe.sh` pin their happy paths exhaustively while the security-load-bearing branches stay unverified: the no-jq path (`command -v jq` failure) and the STATE_DIR symlink-plant / foreign-ownership rejections (`[ ! -L ]` / `[ -O ]`). Trigger/cost: these branches are exactly the CWE-377 defense the hook comments call load-bearing, so an unpinned branch is an unverified security claim; deferred as a batch because the harness needs PATH shims, which is a unit rather than a ride-along. Evidence 2026-09-04: `grep -n "symlink\|-O \|ownership" .claude/hooks/context-size-reminder.probe.sh` → no hits, while the hook itself still carries the guards at lines 30/57/58.
- **TASK-631 — Hook-gate the worktree self-heal `reset --hard` AND-chain** (filed 2026-08, was state:ready size:S).
