# Idea: AI companions in Minecraft

Lila's idea, 2026-11-02. No work now. Promote when Tzurot's agentic features begin development.

**Shape.** Tzurot stays the character's mind, with its persona and memory, and a Minecraft bot is its body. There is no second, weaker personality living in the bot.

**Possible starting points, not checked.** Mineflayer joins a Java Edition world as a player, and Mindcraft connects a model to it. Both are named from memory plus one article, so check their current state first.

**Likely hard parts.**

- Latency: code handles reflexes such as fleeing and eating, and the model decides and talks.
- Knowing what is worth reacting to.
- Token cost: think on events, not constantly.
- Hosting: game, server and bots together are tight on the dev machine, so the server may need to live elsewhere.

**Why it is useful.** It would test memory, tools and staying in character while acting, and failures would be obvious. Start with one character and see whether it is fun before building around it.
